⚙️ Target Repository Required Setup Guide (대상 저장소 필수 설정 가이드)

🔑 1. AI API Keys (Secrets) 설정

Repository Settings → Secrets and variables → Actions 경로에서 사용할 AI 키를 등록하세요:

OPENAI_API_KEY: OpenAI API Key (GPT 모델용)
ANTHROPIC_API_KEY: Anthropic API Key (Claude 모델용)
🔒 2. GitHub Actions Write & PR 권한 허용 (필수)

권한 설정이 꺼져 있으면 PR 푸시 시 403 Permission Denied 에러가 발생합니다.
